# Custom React Hooks

This directory contains reusable React hooks for the ENGIDA application.

## Guidelines

- Keep hooks focused on a single responsibility
- Name hooks with the `use` prefix (e.g., `useAuth`, `useProperty`)
- Include TypeScript types for all hook parameters and return values
- Write tests for custom hooks
- Document hook usage with JSDoc comments

## Examples of hooks to implement:

- `useAuth()` - Authentication state and methods
- `useProperty()` - Property data fetching and mutations
- `useSearch()` - Search functionality
- `useDebounce()` - Debounced values
- `useMediaQuery()` - Responsive design utilities
